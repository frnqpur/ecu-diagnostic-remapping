# Disclaimer

This project package is provided for portfolio review only.

ECU diagnostic and remapping activities involve technical risk. Incorrect wiring, unstable power supply, incompatible ECU files, incorrect calibration data, or improper flashing procedure may cause ECU malfunction, motorcycle issues, data corruption, or hardware damage.

Full functionality requires compatible FTDI hardware, USB-to-K-Line interface, proper ECU connection, stable 12V power, and correct technical procedure.

The following items are intentionally not included:

- Source code
- Original ECU BIN files
- XDF/map definition files
- ECU backup files
- Checksum implementation details
- Seed/key or security-related implementation details
- Private or confidential project data

Any file in the `data/` folder must be treated as dummy or sanitized material only. It must not be used for real ECU flashing.

The recommended  review method is to open the portfolio page, review the screenshots, watch the walkthrough video, read the user guide, and use the executable package only in a controlled environment.
